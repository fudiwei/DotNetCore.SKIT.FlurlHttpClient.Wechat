# SKIT.FlurlHttpClient.Wechat.Work

基于 Flurl.Http 的企业微信 API 客户端 SDK。

## 功能特性

- 封装企业微信 API。
- 支持企业内部开发、第三方应用开发、服务商代开发、智慧硬件开发等模式。
- 提供了企业微信会话内容存档的相关功能封装（基于 C SDK）。
- 提供了企业微信智能机器人的相关功能封装（基于 URL 回调）。
- 提供了 AES、RSA、SHA-1、SHA-256 等算法工具类。
- 提供了 JS-SDK 签名、回调通知事件解析等扩展方法。
