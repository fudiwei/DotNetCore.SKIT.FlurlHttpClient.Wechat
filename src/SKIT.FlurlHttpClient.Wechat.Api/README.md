# SKIT.FlurlHttpClient.Wechat.Api

基于 Flurl.Http 的微信公众平台（订阅号、服务号、小程序、小游戏、小商店、视频号）、微信开放平台 API 客户端 SDK。

## 功能特性

- 封装微信公众平台 & 微信开放平台 API。
- 针对安全鉴权模式接口，请求时自动生成签名（同时兼容 AES+RSA 或 SM4+SM2 算法），无需开发者手动干预。
- 提供了 AES、SHA-1、HMAC-SHA-256 等算法工具类。
- 提供了 JS-SDK 签名、回调通知事件解析等扩展方法。
